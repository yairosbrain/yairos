Y.A.I.R.O.S

התקנת האפליקציה — מחשב · אייפון · אנדרואיד

אותה אפליקציה בכל מכשיר. מתעדכנת אוטומטית בכל פתיחה ועובדת גם לא-מקוון — כי זה בדיוק הקוד של האתר, ארוז כאפליקציה.

מחשב — Windows / Mac / Linux עובד עכשיו

ב-Chrome או Edge:

  1. פתח את yairos.vercel.app
  2. בשורת הכתובת יופיע אייקון התקנה (מסך קטן עם ↓), או תפריט ⋮ ← Install YAIROS
  3. נפתח כחלון אפליקציה נפרד, עם אייקון ב-Start Menu / Applications, נצמד לשורת המשימות

או חבילת Windows (MSIX):

הורד yairos.msix

MSIX = חבילת התקנה של Windows. מ-PWABuilder בוחרים את כרטיס Windows. מיועד בעיקר ל-Microsoft Store; להתקנה ישירה במחשב שלך התקנת Edge למעלה שקולה ופשוטה יותר.

אייפון / אייפד עובד עכשיו

  1. פתח את yairos.vercel.app ב-Safari (לא Chrome)
  2. כפתור השיתוף ⧉ ← הוסף למסך הבית / Add to Home Screen
  3. אייקון YAIROS במסך הבית — מסך מלא, בלי שורת כתובת, אחסון משלו

התראות עובדות רק כשמותקן במסך הבית וב-iOS 16.4+. אפליקציה ב-App Store דורשת Mac + Xcode + חשבון Apple Developer — לא נחוצה לשימוש אישי.

אנדרואיד עובד עכשיו

  1. פתח את yairos.vercel.app ב-Chrome
  2. תפריט ⋮ ← הוסף למסך הבית / Install app

או קובץ APK (עוטף את האתר החי — התוכן תמיד מעודכן):

הורד yairos.apk

אם ההורדה לא עובדת — ה-APK עדיין לא הועלה. עד אז השתמש בהתקנה מהדפדפן למעלה.
